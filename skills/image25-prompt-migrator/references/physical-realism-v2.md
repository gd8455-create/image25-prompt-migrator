# Physical Realism v2：可選轉換設定檔

Physical Realism v2 是 `migration_convert` 的可選 `conversion_profile`。只有在來源本身追求攝影或物理寫實，而且任務要求這類整理時使用；合格的 `migration_repair` 也只能在先前已選用此設定檔，或失敗明確涉及來源中的寫實要求時使用。

它不是 GPT Image 2.5 官方模板、特殊 token、API 參數或自動預設，也不能用於未改寫的遷移基準。套用時必須保留完整 `source_prompt`、標記 `conversion_profile: physical_realism_v2`，並在 `changes` 中揭露修改。

## 轉換順序與界線

1. 先建立來源語意保留表，鎖定身份、人物特徵、動作、物件種類與顏色、服裝、時空、構圖、光源、比例、參考圖角色和明確風格。
2. 依 [來源轉接原則](source-adapters.md) 分離自然語言與專有控制。未確認的 `r/` 標籤、自訂 token、權重、模型資產或負向欄位保持 unresolved；不能因名稱看似寫實就推測作用。
3. 只使用來源已有的畫面意圖，按需要整理為：動作、材質、重力與接觸、光源、相機所見、少量風格。這是可調整的編排順序。
4. 合併真正重複或互相拉扯的描述，將來源中有明確意圖的抽象詞改成可見關係。不得自行增加風、雨、光源、場景物件、皮膚特徵、顆粒或數值。
5. 原稿已清楚時允許零改寫。不要為了展示設定檔而增加寫實細節。

## 寫實語意整理

- 畫質：純宣傳式堆疊只有在不承載獨立意圖時才可合併。實際輸出尺寸、比例、媒介和明確影像風格必須保留。不要把固定焦段、景深或自然光套到所有題材。
- 自然差異：只有來源已要求寫實差異時，才用具體關係表達，例如布料受關節彎曲形成皺摺、頭髮受重力垂落、反射依光源和視角變化。不要新增刮痕、髒污、斑點、顆粒或皮膚瑕疵。
- 頭髮：來源要求自然髮絲時，可先描述整體髮束重量，再保留少量有原因的散髮。既定髮型、髮色、風力或刻意飛揚造型不得被改寫掉。
- 濕度：只有來源包含雨、落水、汗水或潮濕情節時，才澄清表面方向、低窪、遮蔽與接觸位置。不要把所有表面自動改成潮濕或發亮。
- 光與霧：保留來源光源方向、冷暖、範圍與霧的密度。反光依材質處理，不讓每個表面同時閃耀，也不抹掉來源要求的霓虹、舞台光或逆光。
- 紋理：保留材質本身與來源指定的粗針織、金繡、木紋、薄紗、底片顆粒等設計。不要把「寫實」變成到處增加微小紋理或噪點。
- 排除條件：先確認它是自然語言限制還是來源工具的 negative prompt／negative conditioning。只轉換來源中清楚且必要的排除語意，不攜帶來源端數值、權重或隱含機制，也不設定固定項目數。

超現實、魔法、刻意漂浮、顆粒攝影或特殊材質若屬來源意圖，必須保留。這個設定檔只改善寫實語意的清晰度，不能用現實世界物理覆蓋作品設定。
